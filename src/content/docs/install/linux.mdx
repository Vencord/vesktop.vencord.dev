<Aside type="note" title="Read this before installing">
    If possible, **we recommend using native packages instead of the Flatpak**!

    This is because the Flatpak version has various limitations:
    - Rich presence does not properly work
    - You won't be able to drag & drop files unless you grant the Flatpak access to all files

    Don't worry, all native packages except the tarball include automatic updates.

    ---

    ##### Unsure whether to download the x64 or arm64 version?
    - Open a terminal and run `uname -m`.
    - If it outputs `x86_64`, download the x64 version.
    - If it outputs `aarch64`, download the arm64 version.

</Aside>

    AUR (Arch Linux / CachyOS / Omarchy / Manjaro)
</IconHeader>

For most users, we recommend using **vesktop-bin**. Only use **vesktop-git** if you want to build the latest development version from source.\
If you are unsure how to install from the AUR, we suggest [**yay**](https://jguer.github.io/yay/) or [**paru**](https://github.com/morganamilo/paru#installation).
